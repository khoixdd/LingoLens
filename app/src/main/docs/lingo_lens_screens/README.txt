Lingo Lens UI screens
====================

- 24 individual screen crops.
- Source: the supplied 1536x1024 PNG collage.
- Every screen is saved as PNG (RGBA).
- Cropping only: NO resizing, NO JPEG conversion, NO AI upscaling, NO sharpening.
- This preserves the exact source pixels and avoids additional quality loss.
- manifest.json contains the crop coordinates and dimensions for each screen.

For Codex, attach/use the individual PNG files rather than the original collage
so each UI screen receives more visual resolution during inspection.
